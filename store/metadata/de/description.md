Haben Sie genug von der tristen, unformatierten Quelltext-Ansicht Ihres Browsers? Source Code & Font Viewer schafft Abhilfe. Zeigen Sie den Quelltext jeder Webseite an — und formatieren Sie ihn — mit sauberer Einrückung und ansprechender Syntaxhervorhebung, direkt über das Kontextmenü oder mit einem Klick auf das Symbol in der Symbolleiste. Keine unlesbaren Textblöcke mehr. Einfach sauberer, farbiger Code, genau so, wie er sein sollte.

✨ Was Sie erhalten:
• Erstklassige Syntaxhervorhebung für HTML, CSS, JavaScript, JSON & XML
• Automatische Formatierung & Verschönerung — minifiziertes CSS, JS, JSON & HTML lesbar formatieren
• Automatische Formatierung an Ort und Stelle beim direkten Öffnen von CSS/JS/JSON/XML-Dateien
• Interaktive Referenz-Seitenleiste & Verzeichnisbaum — durchsuchen Sie alle externen Skripte, Stylesheets, Schriftarten, Bilder und verknüpften Ressourcen in einem organisierten virtuellen Dateibaum mit Schnellzugriffen
• Geteilte Schnellkopier-Schaltfläche — formatierten Code mit einem Klick kopieren oder über das Dropdown-Menü den Rohcode oder die URL mit sofortiger Rückmeldung kopieren
• Volltextsuche (Cmd/Strg+F) im gesamten Dokument — mit Weiter/Zurück, Groß-/Kleinschreibung, ganzem Wort, regulären Ausdrücken und erweiterten strukturellen Suchmodi (XPath, CSS-Selektoren, JSONPath)
• Ein-Klick-Download des formatierten Quelltexts mit intelligentem Dateinamen — heruntergeladenes HTML wird lokal gerendert und Stylesheets behalten Verweise auf Schriften & Bilder bei
• Integrierter Schriften-Viewer — jede Web-Schriftart (woff2, woff, ttf, otf) mit eigenem Text, Größe, Schriftstärke und Stil probeanzeigen, inklusive Glyphen-Tabelle (Klick auf ein Zeichen zum Kopieren)
• Große Auswahl an hellen und dunklen Themes
• Zeilenumbruch, Zeilennummern & Code-Faltung
• Klickbare Links, um zwischen Ressourcen zu springen, ohne den Viewer zu verlassen
• Ein-Klick-Wechsel zurück zur nativen Browser-Quelltextansicht
• In mehreren Sprachen verfügbar

Ideal für Entwickler, Webdesigner und alle, die HTML-, CSS-, JavaScript-, JSON- oder XML-Quelltext ansehen und formatieren oder Web-Schriftarten untersuchen möchten. Ein sauberer Quelltext-Viewer, JSON/XML-Viewer, Schriften-Viewer und Code-Formatierer in einem Tool.
