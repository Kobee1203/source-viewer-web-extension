厌倦了浏览器平淡无奇、毫无样式的源代码查看器？Source Code & Font Viewer 为此而生。只需从右键菜单点击，或单击工具栏图标，即可查看并格式化任何网页的源代码，享受规范的排版与精美的语法高亮。告别密密麻麻、难以阅读的文本墙，体验干净清爽、富有色彩的代码呈现。

✨ 功能特性：
• 支持 HTML、CSS、JavaScript、JSON 和 XML 的精美语法高亮
• 自动格式化与美化 — 精美排版压缩后的 CSS、JS、JSON 与 HTML
• 直接打开原生 CSS/JS/JSON/XML 文件时自动就地格式化
• 交互式参考侧边栏与站点树 — 在整洁的虚拟文件树中浏览所有外部脚本、样式表、字体、图像及链接资源，并提供快速查看任意资源的快捷方式
• 快速复制组合按钮 — 一键复制格式化代码，也可通过下拉菜单复制原始源代码或 URL，并附带即时反馈
• 全局全文搜索（Cmd/Ctrl+F）— 检索整个源代码而不止可见区域，支持上一个/下一个、区分大小写、全字匹配、正则表达式以及高级结构化搜索模式（XPath、CSS 选择器、JSONPath）
• 一键下载带智能文件名的格式化源代码 — 下载的 HTML 仍可在本地正常渲染，样式表亦能继续关联其字体与图像
• 内置字体查看器 — 自定义示例文本、字号、字重与样式以预览任意 Web 字体（woff2、woff、ttf、otf），并提供涵盖字符的字形网格（点击字形即可复制）
• 多款浅色与深色主题
• 自动换行、行号与代码折叠
• 可点击链接，无需离开查看器即可在资源之间快速跳转
• 一键切换回浏览器原生的源代码视图
• 支持多种语言界面

非常适合开发者、网页设计师以及任何需要查看或格式化 HTML、CSS、JavaScript、JSON 或 XML 源代码或检查 Web 字体的人员。集干净清爽的源代码查看器、JSON/XML 查看器、字体查看器和代码格式化工具于一身。
