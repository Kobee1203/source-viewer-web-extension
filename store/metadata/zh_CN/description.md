厌倦了浏览器自带单调乏味的源代码查看器？Source Code & Font Viewer 为此而生。无论是通过右键菜单还是点击工具栏图标，都能以精美的语法高亮和规范的排版格式查看并格式化任意网页的源代码。告别难以阅读的文字堆叠，享受清晰、美观的代码本色。

✨ 核心功能：
• 支持 HTML、CSS、JavaScript、JSON 和 XML 的精美语法高亮
• 自动格式化与美化 — 将压缩或混淆的 CSS、JS、JSON 和 HTML 一键排版为易读代码
• 直接打开原始 CSS/JS/JSON/XML 文件时自动就地格式化
• 交互式引用侧边栏与网站目录树 — 在结构清晰的虚拟文件树中浏览所有外部脚本、样式表、字体、图片及关联资源，并提供快速查看任意资源的快捷方式
• 快捷双模复制按钮 — 一键复制格式化后的代码，或通过下拉菜单复制原始代码或 URL，带有即时状态反馈
• 全文搜索（Cmd/Ctrl+F） — 搜索整个源代码（不仅限于可见区域），支持上一个/下一个、区分大小写、全字匹配、正则表达式以及高级结构化搜索（XPath、CSS 选择器、JSONPath）
• 智能文件名一键下载 — 下载的 HTML 仍可在本地完美渲染，样式表依然能正确加载其引用的字体与图片
• 内置字体查看器 — 预览任意网页字体（woff2、woff、ttf、otf），支持自定义文本、字号、字重与样式，并提供字符字形网格（点击字形即可快速复制）
• 提供多款浅色与深色主题
• 自动换行、行号显示与代码折叠
• 可点击的超链接，无需离开查看器即可在资源之间无缝跳转
• 一键切换回浏览器原生源代码查看器
• 支持多语言界面

非常适合开发者、网页设计师以及需要查看或格式化 HTML、CSS、JavaScript、JSON、XML 源代码或检查网页字体的用户。集轻量源码查看器、JSON/XML 查看器、字体查看器与代码美化器于一体。
