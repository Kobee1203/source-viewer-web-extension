¿Cansado de mirar el visor de código fuente plano y sin estilo de tu navegador? Source Code & Font Viewer está aquí para solucionarlo. Visualiza —y formatea— el código fuente de cualquier página web con un formato adecuado y un hermoso resaltado de sintaxis, directamente desde el menú contextual o con un solo clic en el icono de la barra de herramientas. Se acabaron los muros de texto ilegibles. Solo código limpio y coloreado, tal y como debería ser.

✨ Lo que obtienes:
• Hermoso resaltado de sintaxis para HTML, CSS, JavaScript, JSON y XML
• Formateo y embellecimiento automático: da formato a CSS, JS, JSON y HTML minificados
• Formateo automático integrado al abrir directamente un archivo CSS, JS, JSON o XML sin formato
• Una barra lateral de referencias interactiva y árbol del sitio: explora todos los scripts externos, hojas de estilo, fuentes, imágenes y recursos vinculados en un árbol de archivos virtual organizado, con accesos directos rápidos para inspeccionar cualquier recurso
• Botón dividido de copia rápida: copia el código formateado con un solo clic, o utiliza el menú desplegable para copiar el código fuente sin formato o la URL con confirmación instantánea
• Búsqueda de texto completo (Cmd/Ctrl+F) en todo el código fuente —no solo en la parte visible— con siguiente/anterior, coincidencia de mayúsculas/minúsculas, palabra completa, expresiones regulares y modos de búsqueda estructural avanzada (XPath, selectores CSS, JSONPath)
• Descarga en un solo clic del código fuente formateado con un nombre de archivo inteligente: el HTML descargado sigue renderizándose localmente y las hojas de estilo continúan encontrando sus fuentes e imágenes
• Un visor de fuentes integrado: previsualiza cualquier fuente web (woff2, woff, ttf, otf) con tu propio texto de muestra, tamaño, grosor y estilo, además de una cuadrícula de glifos de los caracteres que abarca (haz clic en un glifo para copiarlo)
• Una variedad de temas claros y oscuros
• Ajuste de línea, números de línea y plegado de código
• Enlaces en los que se puede hacer clic para saltar entre recursos sin salir del visor
• Cambio en un solo clic de vuelta a la vista de código fuente nativa del navegador
• Disponible en varios idiomas

Ideal para desarrolladores, diseñadores web y cualquier persona que necesite ver o formatear código fuente HTML, CSS, JavaScript, JSON o XML, o inspeccionar una fuente web. Un visor de código fuente limpio, visor de JSON/XML, visor de fuentes y formateador de código, todo en uno.
