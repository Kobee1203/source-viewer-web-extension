¿Cansado de la vista de código fuente sosa y sin formato de tu navegador? Source Code & Font Viewer está aquí para solucionarlo. Visualiza — y formatea — el código fuente de cualquier página web con un sangrado adecuado y un excelente resaltado de sintaxis, directamente desde el menú contextual o con un solo clic en el icono de la barra de herramientas. Adiós a los muros de texto ilegibles. Solo código limpio y coloreado, tal y como debe ser.

✨ Lo que incluye:
• Excelente resaltado de sintaxis para HTML, CSS, JavaScript, JSON y XML
• Formateo y embellecimiento automáticos — imprime de forma legible CSS, JS, JSON y HTML minificados
• Formateo automático en el lugar (in-place) al abrir directamente un archivo CSS/JS/JSON/XML
• Barra lateral interactiva de referencias y árbol del sitio — explora todos los scripts externos, hojas de estilo, fuentes, imágenes y recursos enlazados en un árbol de archivos virtual organizado, con atajos rápidos para inspeccionar cualquier recurso
• Botón dividido de copia rápida — copia el código formateado con un solo clic, o utiliza el menú desplegable para copiar el código sin formato o la URL con confirmación instantánea
• Búsqueda de texto completo (Cmd/Ctrl+F) en todo el documento — con siguiente/anterior, coincidencia de mayúsculas/minúsculas, palabra completa, expresiones regulares y modos avanzados de búsqueda estructural (XPath, Selectores CSS, JSONPath)
• Descarga en un solo clic del código formateado con nombre de archivo inteligente — el HTML descargado se visualiza correctamente en local y las hojas de estilo siguen encontrando sus fuentes e imágenes
• Visor de fuentes integrado — previsualiza cualquier fuente web (woff2, woff, ttf, otf) con tu propio texto de muestra, tamaño, grosor y estilo, además de una cuadrícula con todos sus glifos (haz clic en un glifo para copiarlo)
• Amplia variedad de temas claros y oscuros
• Ajuste de línea automático, numeración de líneas y plegado de código
• Enlaces clicables para navegar entre recursos sin salir del visor
• Cambio en un clic a la vista nativa del navegador
• Disponible en múltiples idiomas

Perfecto para desarrolladores, diseñadores web y cualquiera que necesite ver o formatear código fuente HTML, CSS, JavaScript, JSON o XML — o inspeccionar una fuente web. Un visor de código fuente limpio, visor de JSON/XML, visor de fuentes y formateador de código, todo en uno.
