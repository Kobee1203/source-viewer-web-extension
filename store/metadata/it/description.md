Stanco del solito e noioso visualizzatore del codice sorgente del browser? Source Code & Font Viewer è qui per questo. Visualizza — e formatta — il codice sorgente di qualsiasi pagina web con una formattazione perfetta e un'elegante evidenziazione della sintassi, direttamente dal menu contestuale o con un singolo clic sull'icona della barra degli strumenti. Basta con muri di testo illeggibile. Solo codice pulito e colorato, proprio come dovrebbe essere.

✨ Cosa offre:
• Splendida evidenziazione della sintassi per HTML, CSS, JavaScript, JSON e XML
• Formattazione e riorganizzazione automatica — Pretty-print per CSS, JS, JSON e HTML minimizzati
• Formattazione automatica immediata quando apri direttamente un file CSS/JS/JSON/XML non formattato
• Una barra laterale interattiva di riferimento e albero del sito — esplora tutti gli script esterni, i fogli di stile, i font, le immagini e le risorse collegate in un albero di file virtuale organizzato, con scorciatoie rapide per ispezionare qualsiasi elemento
• Pulsante di copia rapida suddiviso — copia il codice formattato con un solo clic, oppure usa il menu a discesa per copiare il codice sorgente originale o l'URL con feedback istantaneo
• Ricerca full-text (Cmd/Ctrl+F) nell'intero codice sorgente — non solo nella parte visibile — con successivo/precedente, maiuscole/minuscole, parola intera, espressioni regolari e modalità di ricerca strutturale avanzate (XPath, Selettori CSS, JSONPath)
• Download con un solo clic del codice sorgente formattato con un nome file intelligente — l'HTML scaricato viene comunque visualizzato localmente e i fogli di stile continuano a trovare i relativi font e immagini
• Un visualizzatore di font integrato — anteprima di qualsiasi font web (woff2, woff, ttf, otf) con testo di prova personalizzato, dimensione, spessore e stile, più una griglia di glifi dei caratteri coperti (clicca su un glifo per copiarlo)
• Una gamma di temi chiari e scuri
• A capo automatico, numeri di riga e compressione del codice (code folding)
• Link cliccabili per passare da una risorsa all'altra senza uscire dal visualizzatore
• Passaggio con un solo clic al visualizzatore nativo del browser
• Disponibile in più lingue
