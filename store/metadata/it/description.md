Stanco della visualizzazione del codice sorgente predefinita del browser, priva di stile e formattazione? Source Code & Font Viewer è qui per questo. Visualizza — e formatta — il codice sorgente di qualsiasi pagina web con una formattazione impeccabile e una splendida evidenziazione della sintassi, direttamente dal menu contestuale o con un singolo clic sull'icona della barra degli strumenti. Basta con blocchi di testo illeggibili. Solo codice pulito, colorato e ordinato, come dovrebbe sempre essere.

✨ Caratteristiche principali:
• Splendida evidenziazione della sintassi per HTML, CSS, JavaScript, JSON e XML
• Formattazione e rientro automatici — visualizzazione ordinata di CSS, JS, JSON e HTML minificati
• Formattazione automatica immediata (in-place) quando apri direttamente un file raw CSS/JS/JSON/XML
• Barra laterale interattiva dei riferimenti e albero del sito — esplora script esterni, fogli di stile, font, immagini e risorse collegate in una struttura ad albero virtuale, con scorciatoie rapide per ispezionare qualsiasi elemento
• Pulsante combinato di copia rapida — copia il codice formattato con un clic, oppure usa il menu a tendina per copiare il codice grezzo o l'URL con feedback visivo immediato
• Ricerca full-text (Cmd/Ctrl+F) nell'intero documento — con successivo/precedente, maiuscole/minuscole, parola intera, espressioni regolari e modalità avanzate di ricerca strutturale (XPath, Selettori CSS, JSONPath)
• Download in un clic del sorgente formattato con nome file intelligente — l'HTML scaricato si apre correttamente in locale e i fogli di stile continuano a trovare font e immagini
• Visualizzatore di font integrato — visualizza in anteprima qualsiasi font web (woff2, woff, ttf, otf) con testo personalizzato, dimensione, peso e stile, oltre a una griglia completa dei glifi (clicca su un carattere per copiarlo)
• Ampia selezione di temi chiari e scuri
• Ritorno a capo automatico, numeri di riga e compressione del codice (folding)
• Link cliccabili per passare da una risorsa all'altra senza uscire dal visualizzatore
• Passaggio in un clic alla vista sorgente nativa del browser
• Disponibile in diverse lingue

Ideale per sviluppatori, web designer e chiunque debba visualizzare o formattare codice sorgente HTML, CSS, JavaScript, JSON o XML — o esaminare un font web. Un visualizzatore di codice pulito, viewer JSON/XML, visualizzatore di font e formattatore in un'unica estensione.
