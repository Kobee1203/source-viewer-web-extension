ブラウザの味気ないソースビューアにうんざりしていませんか？「Source Code & Font Viewer」がそれを解決します。右クリックのコンテキストメニューやツールバーアイコンのワンクリックで、あらゆるウェブページのソースコードを美麗な構文ハイライトと適切なフォーマットで表示・整形できます。読みづらいテキストの山とはもうおさらば。本来あるべき、クリーンで色鮮やかなコードを手に入れましょう。

✨ 主な機能・特徴:
• HTML、CSS、JavaScript、JSON、XMLの美しい構文ハイライト
• 自動フォーマット＆コード整形 — 圧縮（Minify）されたCSS、JS、JSON、HTMLを読みやすく整形
• 生のCSS/JS/JSON/XMLファイルを直接開いた際の自動インプレース整形
• インタラクティブなリファレンスサイドバー＆サイトツリー — 外部スクリプト、スタイルシート、フォント、画像、リンクされたリソースを整理された仮想ファイルツリーで閲覧し、クイックショートカットで即座に検証
• クイックコピー分割ボタン — ワンクリックで整形済みコードをコピー。ドロップダウンから未整形のソースコードやURLを即座にコピー可能
• ソース全体を対象とした全文検索（Cmd/Ctrl+F） — 表示領域だけでなく全体を検索。前へ/次へ、大文字小文字の区別、単語全体、正規表現、高度な構造検索モード（XPath、CSSセレクター、JSONPath）に対応
• スマートなファイル名での整形済みソースコードのワンクリックダウンロード — ダウンロードしたHTMLはローカルで正常に描画され、スタイルシートのフォントや画像リンクも維持
• 内蔵フォントビューア — 任意のウェブフォント（woff2、woff、ttf、otf）を自由なサンプルテキスト、サイズ、太さ、スタイルでプレビュー可能。収録文字のグリフ一覧も表示（クリックで文字をコピー）
• 豊富なライト＆ダークテーマ
• 行の折り返し、行番号表示、コード折りたたみ機能
• ビューアを離れることなくリソース間を移動できるクリック可能なリンク
• ブラウザ標準のソースビューアへワンクリックで切替可能
• 多数の言語に対応

開発者、ウェブデザイナー、そしてHTML、CSS、JavaScript、JSON、XMLのソースコードの表示・整形やウェブフォントの検証を行いたいすべての人に最適です。クリーンなソースコードビューア、JSON/XMLビューア、フォントビューア、コードフォーマッターが一つに凝縮された拡張機能です。
