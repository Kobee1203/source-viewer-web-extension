ブラウザ標準の味気ないソース表示に物足りなさを感じていませんか？Source Code & Font Viewer がその悩みを解消します。コンテキストメニューやツールバーアイコンのワンクリックで、あらゆるWebページのソースコードを美しく整形＆構文ハイライト付きで表示します。読みにくいテキストの羅列とはもうお別れ。読みやすく色分けされたコード本来の姿で閲覧できます。

✨ 主な機能：
• HTML、CSS、JavaScript、JSON、XML の美しい構文ハイライト
• 自動整形・整形表示 — 圧縮・難読化された CSS、JS、JSON、HTML を見やすくフォーマット
• CSS、JS、JSON、XML ファイルを直接開いた際の自動インプレース整形
• インタラクティブな参照サイドバー＆サイトツリー — 外部スクリプト、スタイルシート、フォント、画像などのリンクされたリソースを仮想ファイルツリーで整理して一覧表示、各アセットへ素早くアクセス
• ワンクリックで使える分割コピーボタン — 整形済みコードを1クリックでコピー、ドロップダウンから未整形ソースやURLのコピーも可能（即時フィードバック付き）
• ソース全体を対象とした全文検索（Cmd/Ctrl+F） — 表示領域だけでなく全体を検索、次へ/前へ移動、大文字/小文字の区別、単語単位、正規表現、高度な構造化検索（XPath、CSSセレクター、JSONPath）に対応
• スマートなファイル名でのワンクリックダウンロード — ダウンロードしたHTMLはローカルでも正しく表示され、スタイルシート内のフォントや画像リンクも保持
• 内蔵フォントビューア — 任意のWebフォント（woff2、woff、ttf、otf）をお好みのサンプルテキスト、サイズ、太さ、スタイルでプレビュー。文字一覧グリフグリッドも搭載（クリックで文字をコピー）
• 豊富なライト＆ダークテーマ
• 行の折り返し、行番号表示、コード折りたたみ
• ビューアを離れることなくリソース間を移動できるクリック可能なリンク
• ブラウザ標準のネイティブソース表示へワンクリックで切り替え
• 多言語対応

Web開発者、デザイナー、HTML/CSS/JavaScript/JSON/XMLのソースコードを表示・整形したい方、またはWebフォントを詳細に確認したいすべての方に最適です。クリーンなソースコードビューア、JSON/XMLビューア、フォントビューア、コードフォーマッタがひとつに。
