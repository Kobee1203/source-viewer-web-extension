Cansado do visualizador de código sem graça do seu navegador? O Source Code & Font Viewer chegou para mudar isso. Visualize — e formate — o código-fonte de qualquer página com formatação adequada e realce de sintaxe elegante, diretamente do menu de contexto ou com um único clique no ícone da barra de ferramentas. Chega de paredes de texto ilegíveis. Apenas código limpo e colorido, como deve ser.

✨ O que você ganha:
• Realce de sintaxe elegante para HTML, CSS, JavaScript, JSON e XML
• Formatação e embelezamento automáticos — formate códigos minificados de CSS, JS, JSON e HTML
• Formatação automática no local ao abrir arquivos brutos de CSS/JS/JSON/XML diretamente
• Barra lateral de referências e árvore do site interativas — navegue por scripts externos, folhas de estilo, fontes, imagens e recursos vinculados em uma árvore de arquivos virtuais organizada, com atalhos rápidos para inspecionar qualquer elemento
• Botão duplo de cópia rápida — copie o código formatado com um clique ou use o menu suspenso para copiar o código original ou a URL com feedback instantâneo
• Pesquisa de texto completo (Cmd/Ctrl+F) em todo o código — não apenas na parte visível — com anterior/seguinte, diferenciar maiúsculas/minúsculas, palavras inteiras, expressões regulares e modos de busca estrutural avançados (XPath, Seletores CSS, JSONPath)
• Download do código formatado com um clique e nome de arquivo inteligente — o HTML baixado continua funcionando localmente, e as folhas de estilo continuam encontrando suas fontes e imagens
• Visualizador de fontes integrado — visualize qualquer fonte da web (woff2, woff, ttf, otf) com seu próprio texto de exemplo, tamanho, peso e estilo, além de uma grade de glifos dos caracteres disponíveis (clique em um glifo para copiar)
• Variedade de temas claros e escuros
• Quebra de linha automática, números de linha e recolhimento de código
• Links clicáveis para navegar entre recursos sem sair do visualizador
• Alterne de volta para o visualizador nativo do navegador com um clique
• Disponível em vários idiomas

Ideal para desenvolvedores, web designers e qualquer pessoa que precise visualizar ou formatar código HTML, CSS, JavaScript, JSON ou XML — ou inspecionar uma fonte da web. Um visualizador limpo de código-fonte, JSON/XML, fontes e formatador de código em uma única ferramenta.
