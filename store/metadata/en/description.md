Tired of staring at your browser's bland, unstyled source viewer? Source Code & Font Viewer is here to fix that. View — and format — the source of any web page with proper formatting and beautiful syntax highlighting, right from the context menu or with a single click on the toolbar icon. No more walls of unreadable text. Just clean, colorized code, the way it should be.

✨ What you get:
• Beautiful syntax highlighting for HTML, CSS, JavaScript, JSON & XML
• Automatic formatting & beautification — pretty-print minified CSS, JS, JSON & HTML
• Automatic in-place formatting when you open a raw CSS/JS/JSON/XML file directly
• An interactive reference sidebar & site tree — browse all external scripts, stylesheets, fonts, images, and linked resources in an organized virtual file tree, with quick shortcuts to inspect any asset
• Quick-copy split button — copy formatted code with a single click, or use the dropdown to copy the raw source code or URL with instant feedback
• Full-text search (Cmd/Ctrl+F) across the entire source — not just the visible part — with next/previous, match case, whole word, regular expressions, and advanced structural search modes (XPath, CSS Selectors, JSONPath)
• One-click download of the formatted source with a smart filename — downloaded HTML still renders locally, and stylesheets keep finding their fonts & images
• A built-in font viewer — preview any web font (woff2, woff, ttf, otf) with your own sample text, size, weight & style, plus a glyph grid of the characters it covers (click a glyph to copy it)
• A range of light & dark themes
• Word wrap, line numbers & code folding
• Clickable links to jump between resources without leaving the viewer
• One-click switch back to the browser's native source view
• Available in multiple languages

Great for developers, web designers, and anyone who needs to view or format HTML, CSS, JavaScript, JSON, or XML source code — or inspect a web font. A clean source code viewer, JSON/XML viewer, font viewer, and code formatter in one.
