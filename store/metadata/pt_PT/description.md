Cansado do visualizador de código básico e sem estilo do seu navegador? O Source Code & Font Viewer resolve esse problema. Veja — e formate — o código-fonte de qualquer página web com formatação adequada e realce de sintaxe elegante, diretamente do menu de contexto ou com um único clique no ícone da barra de ferramentas. Acabaram-se os blocos de texto ilegíveis. Apenas código limpo e colorido, como deve ser.

✨ O que obtém:
• Realce de sintaxe elegante para HTML, CSS, JavaScript, JSON e XML
• Formatação e embelezamento automáticos — formate código minificado de CSS, JS, JSON e HTML
• Formatação automática no local ao abrir ficheiros puros de CSS/JS/JSON/XML diretamente
• Barra lateral de referências e árvore do site interativas — explore todos os scripts externos, folhas de estilo, tipos de letra, imagens e recursos associados numa árvore de ficheiros virtuais organizada, com atalhos rápidos para inspecionar qualquer elemento
• Botão duplo de cópia rápida — copie o código formatado com um único clique ou use o menu pendente para copiar o código-fonte original ou o URL com feedback instantâneo
• Pesquisa de texto integral (Cmd/Ctrl+F) em todo o código-fonte — não apenas na parte visível — com seguinte/anterior, diferenciar maiúsculas/minúsculas, palavras inteiras, expressões regulares e modos de pesquisa estrutural avançados (XPath, Seletores CSS, JSONPath)
• Transferência do código formatado com um clique e nome de ficheiro inteligente — o HTML descarregado continua a funcionar localmente, e as folhas de estilo continuam a encontrar os seus tipos de letra e imagens
• Visualizador de tipos de letra integrado — pré-visualize qualquer tipo de letra da web (woff2, woff, ttf, otf) com o seu próprio texto de exemplo, tamanho, peso e estilo, além de uma grelha de glifos dos carateres disponíveis (clique num glifo para copiá-lo)
• Variedade de temas claros e escuros
• Quebra de linha, números de linha e recolhimento de código
• Ligações clicáveis para alternar entre recursos sem sair do visualizador
• Mude de volta para o visualizador nativo do navegador com um clique
• Disponível em vários idiomas
