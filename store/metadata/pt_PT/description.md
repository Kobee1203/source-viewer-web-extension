Cansado de olhar para o visualizador de código-fonte insípido e sem estilo do seu navegador? O Source Code & Font Viewer está aqui para resolver isso. Veja — e formate — o código-fonte de qualquer página Web com uma formatação adequada e um bonito realce de sintaxe, diretamente a partir do menu de contexto ou com um único clique no ícone da barra de ferramentas. Chega de blocos de texto ilegíveis. Apenas código limpo e colorido, como deve ser.

✨ O que obtém:
• Bonito realce de sintaxe para HTML, CSS, JavaScript, JSON e XML
• Formatação e melhoria automáticas — formate com boa apresentação CSS, JS, JSON e HTML minificados
• Formatação automática no local ao abrir diretamente um ficheiro CSS/JS/JSON/XML não formatado
• Barra lateral de referência e árvore de site interativas — navegue por todos os scripts externos, folhas de estilo, tipos de letra, imagens e recursos associados numa árvore de ficheiros virtual organizada, com atalhos rápidos para inspecionar qualquer elemento
• Botão dividido de cópia rápida — copie o código formatado com um único clique ou utilize o menu suspenso para copiar o código-fonte original ou o URL com confirmação imediata
• Pesquisa de texto integral (Cmd/Ctrl+F) em todo o código-fonte — e não apenas na parte visível — com seguinte/anterior, diferenciar maiúsculas/minúsculas, palavra inteira, expressões regulares e modos de pesquisa estrutural avançados (XPath, Seletores CSS, JSONPath)
• Transferência com um clique do código-fonte formatado com um nome de ficheiro inteligente — o HTML transferido continua a ser apresentado localmente e as folhas de estilo continuam a encontrar os seus tipos de letra e imagens
• Visualizador de tipos de letra integrado — pré-visualize qualquer fonte Web (woff2, woff, ttf, otf) com o seu próprio texto de exemplo, tamanho, peso e estilo, além de uma grelha de glifos dos carateres abrangidos (clique num glifo para o copiar)
• Diversos temas claros e escuros
• Quebra de linha, numeração de linhas e recolha de código
• Ligações clicáveis para alternar entre recursos sem sair do visualizador
• Alternância com um clique de volta para a visualização nativa do código-fonte do navegador
• Disponível em vários idiomas

Excelente para programadores, designers Web e qualquer pessoa que precise de ver ou formatar código-fonte HTML, CSS, JavaScript, JSON ou XML — ou inspecionar um tipo de letra Web.
