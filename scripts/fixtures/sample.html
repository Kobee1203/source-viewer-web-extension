Modern Web Development Inspection

Source Viewer provides seamless inspection and instant formatting for HTML, CSS, JavaScript, JSON, and XML documents. It features CodeMirror 6 syntax highlighting, an interactive site asset tree, customizable color themes, font glyph inspection, and deep structural search capabilities across web pages.

Source Viewer parses and formats web documents on the fly with rich CodeMirror 6 syntax trees.
